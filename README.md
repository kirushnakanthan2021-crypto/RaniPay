# Ravanan Infinity — RaniPay repository

This repository currently contains the RaniPay project landing website for **Ravanan Infinity**.

## Website
- Main page: `index.html`
- Responsive design for mobile and desktop
- Sections for RaniPay, Advanced AI, VR World & Multi-AI, and Future Technologies
- Contact details and a project-status disclaimer
- GitHub Actions workflow: `.github/workflows/pages.yml`

## Publish with GitHub Pages
1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **GitHub Actions** as the source.
4. Open the **Actions** tab and run the workflow, or push a change to `main`.
5. When the workflow completes successfully, open the Pages URL shown in the deployment job or Settings → Pages.

The workflow republishes the static website automatically when `index.html` or the workflow file changes on `main`.
